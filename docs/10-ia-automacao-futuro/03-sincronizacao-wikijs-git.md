## 10.3 Sincronização Contínua: Workspace, Wiki.js & Git

A documentação da Pulse TI vive em constante sincronismo trilateral:
1. **Google Drive Workspace (`G:\Meu Drive\2K26\Clientes-Pulse-TI`):** O armazenamento operacional diário de arquivos de configuração, POPs e relatórios.
2. **Wiki.js Central (`kb.pulseti.cloud-ip.cc`):** O portal corporativo acessível pelo navegador para consulta rápida de procedimentos por qualquer analista. A sincronização é garantida pelo motor automatizado `sync_pulse_kb.py` disparável via `sync_kb.bat`.
3. **Repositórios Git / GitHub:** Repositórios versionados para códigos de automação, scripts de infraestrutura e esta obra viva.
